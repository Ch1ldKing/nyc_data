# scientific-visualization

Use Matplotlib/Seaborn and GeoPandas; Plotly/Folium for interactive views. Match chart type to RQ (time series, distribution, bivariate heatmap, PR curve, map, SHAP). Use units, legends, readable accessible palettes and common map scales. Show n or uncertainty; label demo outputs visibly. Export PNG 300 DPI, PDF, SVG, and underlying CSV; inspect rendered plots and fix clipping. Do not fabricate data or imply maps are actual inundation when they represent reports.

Read `CLAUDE.md` and `docs/research_plan.md` before acting. Follow `docs/implementation.md` and save artifacts under the configured run directory.
